# Авторизация

Методы авторизации и получения информации о пользователях.

## signIn

Авторизация пользователя.

- **Endpoint:** `/signIn`
- **Метод:** POST
- **Параметры:**
  - `login` (string) - Email пользователя
  - `password` (string) - Пароль пользователя
  - `uad` (string) - Уникальный идентификатор устройства
  - `device` (string) - Модель устройства
- **Метод библиотеки:** `await client.login()`

## actor

Получение информации о текущем авторизованном пользователе.

- **Endpoint:** `/actor`
- **Метод:** POST
- **Параметры:**
  - `token` (string) - Токен авторизации
  - `makeOnline` (int) - Флаг онлайн статуса (0 или 1)
- **Метод библиотеки:** `await client.get_actor(make_online=0)`

## user

Получение информации о пользователе по ID.

- **Endpoint:** `/user`
- **Метод:** POST
- **Параметры:**
  - `id` (int) - ID пользователя
  - `token` (string) - Токен авторизации
  - `makeOnline` (int) - Флаг онлайн статуса (0 или 1)
- **Метод библиотеки:** `await client.get_user(user_id=1)`
